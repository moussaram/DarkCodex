Guide d'installation

Comptez 5 à 10 minutes. Choisissez votre système, puis connectez votre compte.

Prérequis Android (Termux) Linux Windows Connexion du compte Vérification Mise à jour Dépannage

1. Ce qu'il vous faut

Un compte DarkCodex

Gratuit. Il se crée à la première connexion, avec Google ou un lien envoyé par email. Créer mon compte

Python 3.10 ou plus récent

Le programme est écrit en Python. Le guide ci-dessous vous dit comment l'installer.

Git

Pour télécharger le projet depuis GitHub.

Une connexion Internet

L'assistant fonctionne via le serveur DarkCodex : il faut être en ligne.

2. Android avec Termux

C'est l'installation recommandée sur téléphone.

Important : installez Termux depuis F-Droid (f-droid.org), pas depuis le Play Store. La version du Play Store n'est plus mise à jour et provoque des erreurs.

Étape 1 — Préparer Termux

pkg update && pkg upgrade -y
pkg install -y python git

Étape 2 — Télécharger DarkCodex

git clone https://github.com/moussaram/DarkCodex.git
cd DarkCodex

Étape 3 — Installer

pip install -r requirements.txt
sh install.sh

Le script crée les commandes darkcodex et DarkCodex et les ajoute à votre PATH. À la fin, il lance une vérification automatique.

Étape 4 — Lancer

darkcodex

Si Termux répond « command not found », fermez-le puis rouvrez-le, ou tapez :

export PATH="$HOME/.local/bin:$PATH"

Facultatif — La dictée vocale

Pour utiliser /dicter, installez l'application Termux:API (depuis F-Droid), puis dans Termux :

pkg install -y termux-api

3. Linux

Le script install.sh est prévu pour Termux. Sous Linux, utilisez la méthode ci-dessous (environnement virtuel).

Étape 1 — Installer Python et Git

Exemple pour Debian ou Ubuntu :

sudo apt update
sudo apt install -y python3 python3-venv python3-pip git

Étape 2 — Télécharger et préparer

git clone https://github.com/moussaram/DarkCodex.git ~/DarkCodex
cd ~/DarkCodex
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

Étape 3 — Créer la commande « darkcodex »

echo "alias darkcodex='PYTHONPATH=\$HOME/DarkCodex \$HOME/DarkCodex/.venv/bin/python -m darkcodex'" >> ~/.bashrc
source ~/.bashrc

Étape 4 — Lancer

darkcodex

4. Windows

Étape 1 — Installer Python et Git

  1. Téléchargez Python 3 sur python.org. Pendant l'installation, cochez « Add python.exe to PATH ».
  2. Téléchargez Git sur git-scm.com et installez-le avec les options par défaut.

Étape 2 — Télécharger DarkCodex

Ouvrez PowerShell :

git clone https://github.com/moussaram/DarkCodex.git
cd DarkCodex
pip install -r requirements.txt

Étape 3 — Installer

powershell -ExecutionPolicy Bypass -File .\install.ps1

Le script crée les commandes darkcodex.cmd et DarkCodex.cmd dans %USERPROFILE%\.local\bin et ajoute ce dossier à votre PATH.

Étape 4 — Lancer

Fermez puis rouvrez PowerShell (ou Windows Terminal), puis :

darkcodex

5. Connecter votre compte

DarkCodex fonctionne uniquement avec un compte : c'est ce qui vous donne accès à l'IA et à vos tokens.

  1. Dans le terminal, tapez /login. Il affiche un code de la forme DARK-XXXX et un lien.
  2. Ouvrez ce lien dans votre navigateur (sur le même appareil ou un autre). C'est la page Lier un appareil.
  3. Connectez-vous avec Google ou par lien email.
  4. Entrez le code DARK-XXXX et validez.
  5. Le terminal confirme la connexion : vous pouvez travailler.
Le code est valable quelques minutes. S'il expire, tapez à nouveau /login pour en obtenir un nouveau.

Vous recevez 5 000 tokens offerts à l'inscription. Tapez /solde pour voir ce qu'il vous reste.

6. Vérifier que tout fonctionne

darkcodex doctor

Cette commande contrôle votre installation. Puis, dans le chat :

/status
/solde

Posez enfin une première question, par exemple « explique ce projet ». Si une réponse arrive, c'est prêt. Passez au guide d'utilisation.

7. Mettre à jour DarkCodex

darkcodex update

La commande vérifie s'il existe une nouvelle version et propose de l'installer. Vous pouvez aussi vérifier la version en ligne sur la page État du service.

8. Dépannage

ProblèmeSolution
command not found (Termux/Linux)Rouvrez le terminal, ou ajoutez le dossier au PATH : export PATH="$HOME/.local/bin:$PATH".
darkcodex introuvable (Windows)Fermez et rouvrez PowerShell. Vérifiez que %USERPROFILE%\.local\bin est dans le PATH.
python introuvableRéinstallez Python en cochant « Add to PATH » (Windows) ou pkg install python (Termux).
La première réponse est très lente (jusqu'à 1 minute)Normal : le serveur se réveille après une période d'inactivité. Les réponses suivantes sont rapides.
« Connexion requise » ou « Session expirée »Tapez /login et refaites la liaison du compte.
Erreur 402 ou « tokens épuisés »Votre solde est à 0. Rechargez votre compte.
Le code DARK-XXXX est refuséIl a peut-être expiré ou contient une faute. Générez-en un nouveau avec /login.
Autre erreurLancez darkcodex doctor : il indique ce qui ne va pas.

Désinstaller

Supprimez le dossier DarkCodex, les commandes créées dans ~/.local/bin (ou %USERPROFILE%\.local\bin) et, si vous le souhaitez, le dossier de données ~/.darkcodex.
