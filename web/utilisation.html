1. Démarrer

Placez-vous dans le dossier de votre projet, puis lancez DarkCodex :

cd mon-projet
darkcodex

Vous êtes dans le chat. Écrivez simplement votre demande en français :

explique ce projet
pourquoi mon test échoue ?
ajoute une fonction qui valide un email

Tapez /help à tout moment pour voir la liste des commandes, et /exit pour quitter.

Première fois dans un projet ? Lancez /projet . : DarkCodex analyse les fichiers et comprend la structure avant de vous répondre.

2. Les trois modes

Le mode décide de la liberté de DarkCodex sur vos fichiers et vos commandes.

ModeComportementDisponible pour
/mode suggestIl propose, vous confirmez chaque action.Tous les comptes
/mode autoeditIl modifie automatiquement les fichiers.Comptes avec un plan payant et des tokens
/mode fullautoAutonomie totale : il enchaîne les actions, tout est affiché en direct.Comptes avec un plan payant et des tokens

/mode sans argument affiche le mode actuel. Pour commencer, restez en suggest.

Qu'est-ce qu'un token ?

Un token mesure la quantité de texte échangée avec l'IA : vos questions, le contexte envoyé et ses réponses. Plus vos échanges sont longs, plus ils consomment. Chaque réponse retire des tokens de votre solde.

Quand le solde est à 0

Le terminal affiche un message avec le lien de recharge. Rendez-vous sur la page Tarifs, achetez un pack, puis tapez /solde : vos nouveaux tokens sont déjà là.

12. Conseils pour de meilleurs résultats

  • Soyez précis. « Corrige le bug de connexion dans auth.py » donne un meilleur résultat que « ça ne marche pas ».
  • Donnez le contexte. Lancez /projet . en début de session et utilisez /contexte pour décrire le projet.
  • Avancez par petites étapes. Une tâche à la fois, puis /tests run pour vérifier.
  • Gardez le contrôle. Restez en mode suggest tant que vous découvrez l'outil.
  • Surveillez vos tokens. /cout et /limite évitent les mauvaises surprises.
  • Relisez toujours. L'IA peut se tromper : relisez les modifications avec /diff avant de les enregistrer avec Git.
