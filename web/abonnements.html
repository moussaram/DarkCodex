Questions sur les paiements

Quels moyens de paiement sont acceptés ?

Le paiement est géré par SasPay, un prestataire de paiement sécurisé : mobile money et carte selon votre pays. Les moyens exacts s'affichent sur la page de paiement.

Mes tokens expirent-ils ?

Non. Un pack acheté reste disponible jusqu'à ce que vous l'ayez utilisé.

Je suis débité mais mes tokens ne sont pas arrivés.

Patientez quelques minutes : le crédit est automatique. Revenez sur cette page, elle vérifie votre dernier paiement. Si rien n'arrive, vérifiez que vous êtes connecté avec le même compte que dans le terminal.

Que se passe-t-il si j'achète deux fois ?

Les tokens s'additionnent. Chaque paiement est crédité une seule fois.

Mes coordonnées bancaires sont-elles stockées chez DarkCodex ?

Non. Le paiement se fait sur la page de SasPay. DarkCodex reçoit seulement la confirmation du paiement.
